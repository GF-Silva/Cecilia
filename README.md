## Installation

The installation tutorials, available for Arch, Ubuntu, and Windows, are in [docs/install.md](docs/install.md)

## How to use

**Run with:**

``` Bash
# To use with debug mode
DEBUG=1 uv run uvicorn cecilia.main:app --reload

# Without debug mode
uv run uvicorn cecilia.main:app --reloa
```

In your preferred browser, access the `interface` on: <http://localhost:8000/>

Or access the documentation with `Scalar` on: <http://localhost:8000/scalar>

Or access the documentation with `Swagger UI` on: <http://localhost:8000/docs>

At the bottom, you will see a field to type an prompt, where you can ask something or wethever.
At the left side of the prompt field, you will see a `+` button, if you click in it, it will display prompt options:

* Change effort
* Change model
* Upload attachment (Just image / audio)

You can choose freely, but notice that not all the models support attachments and the system will show an error if you sending an prompt with a file selected or a file into the chat context when the model not support something (audio / file).

If an error occur mid-stream or at the start, it will display the error at the assistant message output, starting with the header `Error - *info`.
If the error occur before stream, it will display an alert.

### API Interface

* Base URL: `/api/v1/`
* Responses are formatted in JSON
* The API Documentation is auto-generated by `scalar` / `swegger UI` and available at: `/scalar` or `/docs` - Access the running project documentarion at [Cecilia](https://api.cecilia-ai.com/scalar)
